Soal 3: Menentukan Predikat Akademik (Bobot: 30%)
Tambahkan method hitungPredikat() untuk menentukan predikat akademik mahasiswa berdasarkan nilai IPK, dengan ketentuan berikut:
Rentang IPK	Predikat
IPK ≥ 3.75	Dengan Pujian
3.50 ≤ IPK < 3.75	Sangat Memuaskan
3.00 ≤ IPK < 3.50	Memuaskan
IPK < 3.00	Perlu Perbaikan
Tampilkan hasil predikat bersama dengan data mahasiswa.

Contoh Output:
=== Data Mahasiswa ===
Nama: Citra Lestari
NIM: 2440003
Jurusan: Teknik Informatika
IPK: 3.90
Status: Lulus
Predikat: Dengan Pujian

Panduan Pengerjaan
1.	Gunakan konsep OOP (Object-Oriented Programming) dengan benar.
o	Class Mahasiswa dibuat terpisah dari Main class.
o	Gunakan modifier private untuk atribut dan public untuk method.
2.	Simpan minimal 3 objek Mahasiswa ke dalam array, contoh:
Mahasiswa[] daftar = new Mahasiswa[5];
3.	Gunakan loop untuk menampilkan seluruh data mahasiswa.
4.	Gunakan Scanner untuk menerima input dari pengguna.
5.	Sertakan komentar kode pada bagian penting seperti constructor, method, dan logika utama.
